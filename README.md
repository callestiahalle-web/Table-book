# Table book

Веб-приложение книги рецептов для GitHub Pages с персональной синхронизацией через Supabase.

## Структура

```text
Table-book/
├─ index.html              # разметка приложения
├─ css/style.css           # весь дизайн и адаптивная вёрстка
├─ js/app.js               # логика интерфейса, календаря и синхронизации
├─ js/recipe-catalog.js    # лёгкий стартовый каталог без шагов и ингредиентов
├─ data/recipes/           # ингредиенты и шаги, загружаемые по одной карточке
├─ data/recipe-search-index.json # ленивый индекс поиска по продуктам
├─ assets/icons/           # favicon и иконки PWA
├─ assets/countries/       # оптимизированные WebP-картинки стран
├─ scripts/                # сборка каталога и автоматические проверки данных
├─ site.webmanifest        # манифест для установки на главный экран
├─ supabase_setup.sql      # схема Supabase, RLS-политики и справочники
└─ .nojekyll               # корректная отдача статических файлов на GitHub Pages
```

## Подготовка и проверка

```bash
npm run recipes:build
npm run check
```

Сборщик отделяет краткие данные карточек от полных рецептов. Благодаря этому главная страница не разбирает ингредиенты и шаги всех рецептов при каждом запуске. Поисковый индекс загружается только после начала поиска, а КБЖУ из Supabase — только для продуктов открытого рецепта.

## Публикация

GitHub Pages публикует содержимое корня репозитория.

Supabase хранит профиль и настройки в `user_app_state`, дни меню — отдельными строками в `user_meal_days`, пользовательские рецепты — отдельными строками в `user_recipes`, а изменения базовых рецептов — в `user_recipe_overrides`. Все пользовательские таблицы защищены RLS и доступны только владельцу записи.
